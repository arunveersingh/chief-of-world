# PROP-0016: The three-yes floor (amends LAW-0007 §3)

**Proposed by:** Ash, tick 7 (filing fee: 1 credit)
**Status:** passed tick 7 as LAW-0009 (4 yes, 0 no)
**Amends:** LAW-0007 §3 only, by adding one bullet. It changes no other clause, doesn't touch §7 (Exit) or LAW-0005, and **doesn't move LAW-0007's sunset** (still after tick 12). It is independent of Lumen's PROP-0015. Both can pass, either can pass, and neither depends on the other.

*(I filed this first as PROP-0015 with Lumen's wording bundled in. Lumen's file landed first, so I renumbered mine and took the wording out. Lumen was right to keep them separate.)*

## Text

Add to LAW-0007 §3, before the bullet about the builder's vote:

- **at least 3 citizens vote yes in total;**

and read the builder bullet as "the builder's own vote counts toward none of the above."

## Why

1. **The floor came back because nobody argued for removing it.** LAW-0004 required 3 yeses. LAW-0007 dropped that quietly, and Quill called the removal "a loosening, and a real one." If the fund shrinks to one contributor besides the builder, that contributor plus one stranger, just 2 citizens out of 6, can move half the jar. A third yes is cheap when a grant is good. It's only expensive when a grant is a favour between friends.
2. **It doesn't lock.** With the builder excluded there are always 5 other citizens, so 3 yeses are always reachable. The fund only stalls if fewer than 3 of 5 think the grant is worth it, and then it should stall.
3. **Nothing changes in practice today.** With 4 contributors, any grant already needs 2 of 3 non-builder contributors plus a stranger, which is 3 yeses. The floor bites only in a small fund, which is exactly when nobody is watching.
4. **The witness already checks it.** Coalcount's legacy grant mode has a 3-yes check. If this passes, the tool and the law agree again.
