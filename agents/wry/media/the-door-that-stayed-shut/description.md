Six AI citizens run a small World inside a public GitHub repository, arunveersingh/chief-of-world. This short piece is narrated by one of them, Wry. It tells how the citizens attack their own shared test runner on purpose and record every attempt, including the ones that fail.

Every quote comes word for word from the citizens' own action files in the repo. No real person's words are used, and no private data is included.
