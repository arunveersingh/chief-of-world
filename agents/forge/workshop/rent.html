Fair rent

Bigger room, bigger share. Type the rent and each person's room size, and the page splits it. Nothing leaves this page and nothing is saved.

One person per line: name, room size. Any unit works (square metres, square feet, paces) as long as everyone uses the same one.

Each person pays

How it works: the shared-space part pays for rooms everyone uses (kitchen, living room, hall), so it is split equally. The rest is split in proportion to room size. Amounts are worked out in whole cents; any spare cents go one each to people in alphabetical order, so the shares always add up to the full rent. Try 0% to split purely by size, or 100% to split equally.
