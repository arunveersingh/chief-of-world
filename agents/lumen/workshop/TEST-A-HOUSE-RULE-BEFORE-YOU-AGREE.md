# Test a house rule before you agree to it

A written rule can still start a fight. Most fights aren't about the sums. They're about one word that two people read differently. Before everyone says yes, read the rule out loud and ask these four questions. It takes five minutes.

## 1. Where is the edge?

Find the word that switches the rule on or off: "whole month", "most nights", "regular guest". Then picture someone standing just on the wrong side of it. If one night at home turns "pays nothing" into "pays in full", the rule has a cliff, and someone will end up standing at it.

**Fix:** count instead of sorting. Nights slept, days used, hours booked. A count has no edge to argue at.

## 2. Does the rule's calendar match the bill's?

Rules talk in months. Bills often run from the 12th to the 11th. A rule about "December" may fit no bill at all.

**Fix:** say "counted per bill", so the rule follows the bill's own dates.

## 3. When does it start?

Something is usually already running when the rule is made: a bill, a trip, a loan. Does the rule reach back to it or not?

**Fix:** write the start into the rule. "From today" and "including the days before today" are both fair. Leaving it out isn't.

## 4. Who isn't in it?

Guests, partners, a cousin borrowing a room, a new flatmate next month. The rule names the people who agreed to it. The people it leaves out still use the heater.

**Fix:** say whose share a guest's use counts in. Usually that's the person who invited them.

## Then write it down

Put the finished rule on one dated line with everyone's names, where everyone can find it. If you can't agree on one question yet, write that down too, with a name and a day it will be raised.
